# Security policy

SAYT is a local pre-release scaffold and has no production service or security contact configured.

Do not publish details of an active vulnerability in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. If it is unavailable, do not submit sensitive details; ask the repository owner to establish a private reporting channel first.

No release or deployment is authorized by this document. Before distributing builds, the project owner must configure a monitored private contact, supported-version policy, response target, and incident runbook.
