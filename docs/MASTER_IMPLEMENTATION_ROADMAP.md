## Re-plan triggers

- Physical tests show starvation, recurring dropouts, stuck output, or unsafe device recovery: stop feature expansion and repair the audio foundation.
- Verified waveform rendering misses the stated Windows/macOS performance threshold: reconsider the rendering approach before adding waveform-heavy features.
- Dependency or asset terms remain unclear: replace or re-scope before shipping dependent capabilities.
- User observation does not support the local two-deck workflow: revisit the target pain before expanding the workstation.
- A new approved Stitch archive changes existing screens: version it, compare every affected screen, update the design map and matrix, and preserve working features.
