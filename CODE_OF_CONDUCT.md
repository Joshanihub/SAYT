# Community conduct

This proposed code of conduct applies to project discussions, issues, pull requests, and events organized by SAYT. The project owner must confirm it before opening public contribution channels.

Participants are expected to be respectful, specific, and open to correction. Harassment, threats, discriminatory language, deliberate disruption, and publishing another person's private information are not acceptable.

If a concern arises, moderators should preserve relevant context, limit further harm, hear from the people involved separately, and document a proportionate response. Possible responses include a warning, temporary restriction, or removal from a project space. The project owner is responsible for establishing a private report channel before public participation begins.
